# ใช้ SQLite สำหรับโปรเจกต์รอบแรกในเครื่อง

ผู้พัฒนาเลือก SQLite ผ่าน Prisma ใน Q12 เพราะรอบแรกมุ่งเรียนรู้และสาธิตในเครื่องภายในประมาณ 1–2 วัน จึงลดงานตั้ง database server เมื่อเทียบกับเริ่ม PostgreSQL โดยยังฝึกความสัมพันธ์ข้อมูลและ migrations ได้ แลกกับการที่สภาพแวดล้อมนี้ยังไม่พิสูจน์การใช้งานฐานข้อมูลบนระบบออนไลน์หรือหลาย instance หากเปลี่ยนฐานข้อมูลต้องตรวจ migrations และ tests ใหม่
