# 3. กติกาการทำงานและการเรียนรู้

1. ใช้ AI coding agent ช่วยพัฒนา โดยแบ่งงานเป็นขั้นตอนที่ตรวจสอบได้
2. เก็บ prompts, plans และบทสนทนาจริงระหว่างทำงาน ปิดข้อมูลลับก่อนเก็บใน repo หรือเผยแพร่
3. ทุกข้อกล่าวอ้างเกี่ยวกับพฤติกรรมต้องมี test หรือหลักฐานเฉพาะเจาะจงรองรับ แยกการตรวจด้วยมือออกจาก automated tests
4. บันทึกข้อผิดพลาดจริง วิธีตรวจพบ และวิธีแก้ ห้ามสร้างเรื่องผิดพลาดหรือ transcript ย้อนหลังให้ดูครบเกณฑ์
5. อ่านโค้ดและอธิบายส่วนสำคัญได้ก่อนถือว่างานนั้นเสร็จ
6. Commit เป็นช่วงที่มีความหมาย เก็บประวัติการพัฒนาและการแก้ปัญหาจริง
7. ใช้บริการ บัญชี และข้อมูลที่สร้างหรือมีสิทธิ์ใช้สำหรับโปรเจกต์นี้เท่านั้น

## จังหวะการทำงาน

กำหนดงานย่อย → ให้ AI ช่วย → อ่าน diff และทดลอง → ตรวจด้วย tests → อธิบายผล → บันทึกและ commit

ใช้คำถามทบทวนแทนการสัมภาษณ์: token ถูกตรวจที่ไหน, owner มาจากไหน, ผู้ใช้อีกคนเข้าถึงข้อมูลได้หรือไม่ และจะพิสูจน์คำตอบอย่างไร

ไม่จำเป็นต้องบันทึกวิดีโอหรือจัดสอบสด จุดสำคัญคือความเข้าใจและหลักฐานที่ตรงกับงานจริง
