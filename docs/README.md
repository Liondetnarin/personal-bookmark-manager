# เอกสาร Personal Bookmark Manager

เริ่มที่ [ข้อกำหนดโปรเจกต์](Full-Stack-Developer-Test-Details.md) แล้วอ่าน page-1 ถึง page-8 สำหรับรายละเอียดแต่ละด้าน

## การปรับเอกสารสำหรับโปรเจกต์ส่วนตัว

- เขียน Markdown เดิมทั้งเก้าไฟล์ใหม่ให้เป็นบริบทการฝึกทักษะและ portfolio
- ใช้ Auth0 และบัญชีของตนเอง แทน tenant, Client ID, audience และบัญชีทดสอบจากภายนอก
- คง stack, API, ความสัมพันธ์ข้อมูล, privacy, seed สองผู้ใช้ และกระบวนการตรวจงาน AI
- เปลี่ยนการส่งงาน การสัมภาษณ์ และคะแนน เป็นหลักฐาน portfolio และเกณฑ์ตรวจตนเอง
- ระบุการตรวจสอบเวอร์ชันก่อนเริ่มงานและกรอบเวลา 1–2 วัน
- ไม่สร้างแอปหรือเชื่อมบริการในขั้นปรับเอกสารนี้

## ต้นฉบับและ Git

Full-Stack-Developer-Test.pdf เก็บไว้เป็นต้นฉบับส่วนตัวโดยไม่แก้ไข ไม่ใช้เป็นสเปกปัจจุบันและไม่เผยแพร่รวมกับ portfolio

หลังยืนยัน Q15 ปรับ .gitignore ให้เก็บ Markdown ที่เขียนใหม่และ docs/adr/*.md ใน Git ได้ ส่วน PDF ต้นฉบับและไฟล์ชนิดอื่นใน docs ยังคงถูก ignore ไม่เผยแพร่รวมกับ portfolio
