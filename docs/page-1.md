# 1. ภาพรวมโปรเจกต์

Personal Bookmark Manager เป็นโปรเจกต์ส่วนตัวสำหรับฝึกพัฒนา Full-stack ด้วย AI และนำผลงานไปประกอบ portfolio ไม่มีการส่งงานหรือการประเมินจากองค์กรภายนอก

เป้าหมายคือสร้างแอปบันทึกลิงก์ส่วนตัวที่ใช้งานได้ พร้อมหลักฐานว่าผู้พัฒนาเข้าใจ ตรวจสอบ และแก้ไขโค้ดที่ทำร่วมกับ AI ได้

## เวลาและขอบเขต

ใช้เวลาประมาณ 1–2 วันของการทำงานแบบมีสมาธิ เป็นกรอบวางแผน ไม่ใช่การรับรองว่าจะเสร็จทุกส่วน เน้น Backend API และ Frontend สองหน้าหลัก การยืนยันตัวตน การแยกข้อมูลผู้ใช้ และ automated tests ก่อนฟีเจอร์เสริม

## ผลลัพธ์การเรียนรู้

- แบ่งโจทย์เป็นงานเล็กและเขียนเกณฑ์ยอมรับก่อนให้ AI ทำงาน
- อ่านและอธิบายเส้นทางตั้งแต่ล็อกอิน เรียก API จนถึงฐานข้อมูลได้
- ตรวจพบข้อผิดพลาดด้วยหลักฐาน และแก้ไขพร้อมทดสอบซ้ำ
- อธิบายการตัดสินใจและข้อจำกัดด้วยคำพูดของตนเอง
- จัดทำผลงานที่ผู้อื่นติดตั้งและตรวจสอบได้
