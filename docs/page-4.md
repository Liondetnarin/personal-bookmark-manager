# 4. ผลิตภัณฑ์และความเป็นส่วนตัว

สร้างสองส่วนคือ Backend API และ Frontend สำหรับบันทึกลิงก์ไว้อ่านภายหลัง ผู้ใช้ที่ล็อกอินแล้วจัดเก็บ Bookmarks และจัดกลุ่มเป็น Collections ของตนเองได้

## ข้อกำหนดหลัก

ข้อมูลทุกชิ้นเป็นส่วนตัวของเจ้าของ ผู้ใช้ A ต้องไม่สามารถอ่าน แก้ไข ลบ หรืออนุมานการมีอยู่ของข้อมูลผู้ใช้ B ผ่าน API ได้

ไม่มีรายการสาธารณะ ฟีดรวม หรือหน้าค้นหาข้อมูลของผู้ใช้อื่น การกรอง รายการย่อย และความสัมพันธ์ระหว่างข้อมูลต้องรักษากฎเดียวกัน

ให้บันทึกวิธีบังคับ ownership และพฤติกรรมเมื่อเรียก ID ของผู้อื่นใน API_DESIGN.md พร้อม tests ที่ตรวจทั้งข้อมูลตอบกลับและผลต่อฐานข้อมูล

ข้อมูลสาธิตใช้ข้อมูลสมมติและลิงก์ตัวอย่างที่สร้างขึ้นเอง ห้ามนำบัญชีหรือข้อมูลจากแบบทดสอบภายนอกมาใช้
