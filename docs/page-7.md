# 7. เอกสารและหลักฐานสำหรับ portfolio

โครงสร้างเป้าหมายต่อไปนี้ยังไม่ใช่การรับรองว่าไฟล์หรือระบบถูกสร้างแล้ว:

| ตำแหน่ง | เนื้อหา |
| --- | --- |
| /backend | NestJS API, Prisma schema, migrations, seed และ tests |
| /frontend | React application |
| AGENTS.md หรือไฟล์กฎที่เทียบเท่า | ขอบเขต คำสั่ง และข้อกำหนดสำหรับ agent |
| /.agent/ หรือโฟลเดอร์ที่เครื่องมือใช้จริง | ความสามารถใช้ซ้ำอย่างน้อยหนึ่งอย่าง พร้อมวิธีใช้และหลักฐานว่าใช้จริง |
| API_DESIGN.md | API contract, privacy enforcement และข้อผิดพลาดจริงที่พบ/แก้ |
| DECISIONS.md | ADR สั้น ๆ: บริบท ทางเลือก เหตุผล trade-offs และวิธีสั่ง AI |
| AI_WORKFLOW.md | สรุป 1–2 หน้า: tools/models, การแบ่งงาน, สิ่งที่ได้ผล/ไม่ได้ผล และต้นทุนเท่าที่มีข้อมูลจริง |
| /transcripts/ | บทสนทนาจริงที่ปิดข้อมูลลับแล้ว |
| README.md | เป้าหมาย stack วิธีตั้งค่า รันแอป รัน tests และสิ่งที่เสร็จ/ยังไม่เสร็จ |

พยายามเก็บตัวอย่าง 2–3 จุดที่ AI ทำได้ดีและ 2–3 จุดที่ต้องแก้หากเกิดขึ้นจริง หากมีน้อยกว่านั้นให้รายงานตามจริง ไม่สร้างเหตุการณ์เพื่อให้ครบจำนวน

เก็บ commit เป็นขั้นตอนที่มีความหมาย ไม่รวบงานทั้งหมดเป็น initial commit เดียวเพื่อให้ผู้อ่านเห็นพัฒนาการ

นำเสนอเป็นโปรเจกต์ฝึกส่วนตัว อธิบายส่วนที่ผู้พัฒนาตัดสินใจและส่วนที่ AI ช่วย ไม่อ้างว่าเป็นงานที่ส่งหรือผ่านการประเมินจากองค์กรใด

ใช้เฉพาะเอกสารที่เขียนสำหรับโปรเจกต์นี้ในการเผยแพร่ ไม่รวม PDF ต้นฉบับหรือข้อมูลบัญชีภายนอก ตรวจข้อมูลลับในไฟล์และประวัติก่อนเผยแพร่
