# 2. ทักษะที่ต้องการฝึก

| ทักษะ | หลักฐานที่ควรได้ |
| --- | --- |
| แบ่งงานและเขียนสเปก | งานย่อยมีขอบเขตและเกณฑ์ยอมรับที่ตรวจสอบได้ |
| ตรวจงาน AI | อ่าน diff อธิบายจุดเสี่ยง และตรวจโค้ดที่ดูถูกต้องแต่ทำงานผิด |
| Verification | Tests ตรวจพฤติกรรมจริง รวมทั้งกรณีผิดพลาดและความเป็นส่วนตัว |
| คุมทิศทางและแก้ปัญหา | บทสนทนาจริงแสดงการปรับคำสั่งเมื่อผลลัพธ์ไม่ตรงเป้าหมาย |
| ตั้งค่า Agent | กฎของ repo และความสามารถใช้ซ้ำอย่างน้อยหนึ่งอย่างที่ใช้จริง |
| ตัดสินใจเชิงวิศวกรรม | บันทึกทางเลือก เหตุผล และสิ่งที่ยอมแลก |
| สื่อสาร | อธิบายสิ่งที่ตนเองทำ สิ่งที่ AI ช่วย และข้อจำกัดได้ |

หลังแต่ละส่วน ให้ผู้พัฒนาลองอธิบายโค้ดหรือแก้พฤติกรรมเล็ก ๆ แล้วใช้ tests ตรวจผล เก็บประเด็นที่ยังไม่เข้าใจไว้ทบทวน ไม่ต้องทำเสมือนว่าเข้าใจทุกอย่างตั้งแต่แรก
